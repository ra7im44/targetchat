🔒 Widget Security Tester

Use this page to verify that your Domain Lock is working.

Step 1: Get your Embed Code

Go to your Dashboard > Settings > Install and copy your widget script.

Step 2: Edit this file

Click "Edit" on this file and paste your script below this line.

Step 3: Test the Lock

1. Go to your Dashboard and set Allowed Domains to: google.com

2. Refresh this page.

Result: Use F12 (Console). You should see a 403 Forbidden error, and the widget will NOT load.

3. Go back and set Allowed Domains to: * (or empty).

4. Refresh this page.

Result: The widget should appear successfully.
